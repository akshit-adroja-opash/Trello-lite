## 6. Summary — Items That Must Be Fixed

The following are **incomplete or missing** and will directly affect evaluation:

1. **Assignee picker in Card Detail** — assignees can be viewed but not added/changed from the UI.
2. **Filter by assignee and filter by due date** — both mentioned in the spec, neither exists.
3. **`N` keyboard shortcut** — spec says `N = new card`; only `?`, `/`, `Esc` are wired up.
4. **`react-window` virtualisation not actually used** — `FixedSizeList` is never rendered; the threshold check exists but falls back to a plain div.
5. **`usePresence` hook is dead code with wrong event names** — uses `join-board`/`presence-update` instead of `board:join`/`board:presence`; never called anywhere.
6. **Board/Column/Card curl examples missing from README** — only auth + workspace are documented.
7. **`frontend/.env.example` missing** — reviewer cannot know which env vars the frontend needs.
8. **No video walkthrough** — required deliverable.
9. **No Prettier config** — spec requires consistent formatting.
10. **No backend ESLint config** — spec says "code passes a quick lint".
11. **Board view not mobile-friendly at 375 px** — fixed-width columns overflow on small screens.
12. **No comment activity action** — spec lists `commented` as an activity type; only create/update/move/delete are logged.
13. **Exponential backoff is Socket.IO default, not a custom implementation** — spec asks for explicit exponential backoff on reconnect.
